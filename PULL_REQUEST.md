# Pull Request - Software Deterministico Doganale

## Summary
Questa Pull Request rilascia formalmente l'architettura core, l'interfaccia utente responsive e la logica di gestione dinamica della piattaforma software deterministico doganale. Import Hub.

## Elenco delle modifiche principali
- **Frontend & UI**: Sviluppo dell'interfaccia utente multi-colonna in dark-mode nativa.
- **Data Engine & Business Logic**: Integrazione PDF.js e motore JS per riconoscimento automatico (Invoice, Packing List, HAWB).
- **Modularità e Gestione Conflitti**: Sistema di tracciamento visivo per origine dato e anomalie.
